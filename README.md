# 📞 Call Centre Performance & Agent Analytics Dashboard | Power BI

## 📌 Project Overview

This project features an interactive **Call Centre Performance Dashboard** built using Microsoft Power BI to analyze call centre operations, customer satisfaction, resolution rates, and agent performance.

The dashboard provides insights into call volume, month-over-month performance, departmental call distribution, customer ratings, and agent-level productivity to support data-driven decision-making.

## 📊 Dashboard Pages

### 1. Call Centre Performance Dashboard
- **Total Calls:** Tracks the overall number of calls received.
- **Month-over-Month Comparison:** Compares call volume with the previous month.
- **Resolution Rate:** Measures the percentage of calls resolved.
- **Average Talk Duration:** Monitors average call handling duration and monthly changes.
- **Average Speed of Answer:** Tracks how quickly agents answer incoming calls.
- **Answered vs. Unanswered Calls:** Analyzes call outcomes by volume and percentage.
- **Department-wise Calls:** Compares call volumes across departments.
- **Customer Ratings:** Visualizes rating distribution and overall customer satisfaction.
- **Top-Performing Agent:** Highlights the leading agent based on performance metrics.
- **Busiest Time Analysis:** Identifies the busiest day, time, and period of calls.

### 2. Agent Performance Dashboard
- **Agent-wise Performance:** Compares individual agents across key metrics.
- **Calls Handled:** Tracks the number of calls managed by each agent.
- **Answered Call Percentage:** Evaluates agent call-answering performance.
- **Resolution Rate:** Measures the percentage of calls resolved by agents.
- **Average Speed of Answer:** Compares agent responsiveness.
- **Agent Ratings:** Displays ratings to help evaluate customer satisfaction.
- **Interactive Agent Selection:** Enables users to explore individual agent performance.
